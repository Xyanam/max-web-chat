# Веб-чат MAX

Простой веб-чат для мессенджера MAX на React и TypeScript. Работает через HTTP API [GREEN-API для MAX](https://green-api.com/max).

Возможности:

- подключение по `idInstance` и `apiTokenInstance`;
- новый чат по номеру телефона (Россия +7, Беларусь +375);
- отправка и получение текстовых сообщений;
- статусы доставки и прочтения;
- имя и аватар собеседника.

## Требования

- Node.js 20.19+ или 22.12+ и npm.
- Инстанс GREEN-API для MAX в статусе «авторизован» ([консоль GREEN-API](https://console.green-api.com/)).

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Файл `.env` не нужен: данные для подключения вводятся в интерфейсе.

Сборка и проверки:

```bash
npm run build      # продакшн-сборка в dist/
npm run preview    # просмотр собранной версии
npm test           # unit-тесты
npm run lint       # линтер
```

## Настройка инстанса

В консоли GREEN-API (инстанс → «Изменить»):

- поле `webhookUrl` должно быть **пустым**, иначе уведомления не приходят через HTTP API;
- должны быть включены уведомления о входящих сообщениях, о сообщениях, отправленных с телефона, и о статусах доставки и прочтения.

Если уведомления выключены, после подключения приложение покажет предупреждение с кнопкой «Включить». Инстанс перезапустится, настройки применятся в течение 5 минут.

## Как пользоваться

1. Введите `idInstance` и `apiTokenInstance`. Адрес API подставится автоматически; если в консоли указан другой `apiUrl`, вставьте его.
2. Нажмите карандаш или «Новый чат», выберите страну и введите номер. Приложение найдёт аккаунт MAX методом `CheckAccount`.
3. Пишите сообщение: Enter — отправить, Shift+Enter — новая строка.
4. Ответы приходят автоматически: приложение опрашивает очередь `ReceiveNotification` и подтверждает каждое уведомление методом `DeleteNotification`.

## Ограничения

- Только текст: медиа показываются как «не поддерживается», групповые чаты не отображаются.
- История хранится в `localStorage` браузера; старая переписка из журналов GREEN-API не загружается. Уведомления ждут в очереди 24 часа, а сообщения, отправленные при выключенных уведомлениях, не придут.
- Очередь уведомлений общая для инстанса: не открывайте чат в нескольких вкладках и не подключайте к тому же инстансу другого бота.
- Данные для входа хранятся в `sessionStorage`, а при отметке «Запомнить на этом устройстве» — в `localStorage`. Токен передаётся только в GREEN-API.
